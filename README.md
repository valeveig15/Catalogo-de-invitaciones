# ArteDeco Studio · Catálogo XV · V4

Esta versión amplía el catálogo a **10 modelos** y corrige los puntos indicados en la revisión.

## Cambios principales

- Se mantienen los dos primeros conceptos, pero el modelo 01 abandona el rosa y pasa a una paleta **champagne + sage + marfil**.
- Se rediseñaron en el modelo 01 los íconos de **fiesta**, **dress code** y **traslados**, todos con microanimaciones propias.
- La caja de regalo abre la tapa más hacia la izquierda para dejar libres los destellos.
- El disco de la playlist gira de forma continua y visible.
- Se agrandó la tipografía general, botones, textos de información y footer de ArteDeco Studio.
- La música ahora funciona con **10 archivos MP3 locales incluidos** en `assets/music/`. Cada modelo tiene su propia pista demo original. Los navegadores que bloqueen autoplay inician el audio en la primera interacción del visitante.
- Modelo 03: cuenta regresiva centrada, números más legibles y nueva galería nocturna tipo mosaico.
- Modelo 04: nueva imagen de portada, nuevo símbolo animado para el countdown, sección de información reemplazada por `Party Guide`, y regalo rediseñado.
- Modelo 05: nueva portada botánica, imágenes integradas a la estética de jardín, nueva sección de detalles, regalo centrado con animación propia, playlist animada y nuevo ícono animado de confirmación.
- Se agregaron cinco modelos totalmente nuevos:
  - 06 · Cobalt Riviera
  - 07 · Velvet Noir
  - 08 · Aqua Pop
  - 09 · Disco Lilac
  - 10 · Terra Botanica

## Archivos

- `index.html`
- `style.css`
- `script.js`
- `manifest.json`
- `assets/music/*.mp3`

## Música

Las diez pistas son loops demo originales generados para este catálogo. No dependen de URLs externas ni de servicios de streaming.

## Publicación

Subí toda la carpeta a la raíz del repositorio de GitHub Pages, conservando la carpeta `assets/music/`.
