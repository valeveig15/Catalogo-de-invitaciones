# Catálogo de invitaciones digitales de XV años · V3

Versión V3 del catálogo. Se conservaron **sin cambios de concepto los modelos 01 y 02**, y se rediseñaron desde cero los modelos 03, 04 y 05 para que cada uno tenga una identidad mucho más marcada.

## Modelos

- **01 · Aurora Rose** — editorial rosa, suave y elegante.
- **02 · Neon Bloom** — noche neon / club.
- **03 · Lunar Chrome** — editorial nocturna, azul profundo y plata; composición asimétrica tipo revista, gran número 15, retrato vertical, galería tipo filmstrip y tarjetas cromadas.
- **04 · Cherry Pop Club** — pop/Y2K/disco; damero, stickers, ticket de entrada, bola de espejos, polaroids, bubbles de información y tracklist interactiva.
- **05 · Secret Garden** — perla/lavanda; arco fotográfico, carta con sello, composición de álbum artesanal, cintas informativas y tarjetas de inspiración jardín.

## Funciones compartidas

- Música diferente en cada modelo.
- Cuenta regresiva.
- Google Maps y botón para agendar.
- Galerías ampliables con lightbox.
- Dress code, Instagram/hashtag, traslados y horarios.
- Regalos, sugerencia de canciones y RSVP.
- Navegación horizontal entre modelos y scroll vertical dentro de cada invitación.
- Diseño responsive y soporte para `prefers-reduced-motion`.
- Footer comercial de ArteDeco Studio.

## Música

Las pistas instrumentales incluidas son:

- `assets/music/aurora-pop.mp3`
- `assets/music/neon-club.mp3`
- `assets/music/midnight-house.mp3`
- `assets/music/cherry-latin.mp3`
- `assets/music/pearl-dance.mp3`

Para producción pueden sustituirse por MP3 licenciados cambiando la propiedad `music` de cada modelo en `script.js`.

## Fotos

Las fotografías de demostración se cargan desde Unsplash. En una invitación real conviene sustituirlas por fotografías de la quinceañera optimizadas en WebP/JPEG.

## Publicación

Subir `index.html`, `style.css`, `script.js`, `manifest.json` y la carpeta `assets/` a la raíz del repositorio de GitHub Pages.
