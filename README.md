# Catálogo de invitaciones digitales de XV años · V2

Rediseño inspirado en el nivel visual y funcional de la invitación de boda de referencia, pero con identidad propia para XV años.

## Qué incluye

- 5 modelos visuales completos: Aurora Rose, Neon Bloom, Midnight Silver, Cherry Disco y Pearl Garden.
- Portadas full-screen con fotografía, XV destacado, nombre, fecha y animación sutil.
- Cuenta regresiva individual.
- Sección de fiesta con foto, ubicación, Google Maps y Google Calendar.
- Galería fotográfica con lightbox.
- Dress code, Instagram/hashtag, traslados y horarios.
- Regalo con caja animada.
- Sugerencia de canción para la playlist.
- Info útil y confirmación de asistencia.
- Música de fondo diferente en cada modelo.
- Navegación horizontal entre modelos y scroll vertical dentro de cada invitación.
- Diseño responsive y soporte para `prefers-reduced-motion`.
- Footer comercial de ArteDeco Studio.

## Música

Las 5 pistas incluidas son instrumentales originales generadas para este demo (no son copias de canciones comerciales):

- `assets/music/aurora-pop.mp3` — dance-pop suave.
- `assets/music/neon-club.mp3` — electro / club.
- `assets/music/midnight-house.mp3` — house elegante.
- `assets/music/cherry-latin.mp3` — latin-pop / dembow instrumental.
- `assets/music/pearl-dance.mp3` — dance-pop luminoso.

Para producción, se pueden reemplazar por archivos MP3 licenciados manteniendo los mismos nombres o cambiando la propiedad `music` de cada modelo en `script.js`.

## Fotos

Las fotos del demo se cargan desde Unsplash. Para una invitación real, conviene reemplazar las URLs de cada modelo por las fotos de la quinceañera, optimizadas en WebP/JPEG.

## Publicación

Subir `index.html`, `style.css`, `script.js`, `manifest.json` y la carpeta `assets/` a la raíz del repositorio de GitHub Pages.
